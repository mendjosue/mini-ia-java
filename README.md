# Práctica 2 — Mini-IA en Java

## Preguntas de reflexión

1. **¿Qué diferencia existe entre `int` y `double`?**
   → `int` almacena números enteros sin decimales; `double` almacena números con punto decimal.

2. **¿Para qué utilizamos `Scanner`?**
   → Para leer datos que el usuario escribe desde el teclado (entrada de información).

3. **¿Qué diferencia existe entre `=` y `==`?**
   → `=` sirve para asignar un valor a una variable; `==` sirve para comparar si dos valores son iguales.

4. **¿Qué función cumple `if`?**
   → Evalúa una condición: si es verdadera, ejecuta el bloque de código correspondiente.

5. **¿Cuándo utilizarías `switch` en lugar de `if`?**
   → Cuando hay muchas opciones fijas y discretas (ej: menú con números 1, 2, 3...), se lee más ordenado.

6. **¿Cuál es la diferencia entre `while` y `do-while`?**
   → `while` revisa la condición ANTES de ejecutar; `do-while` ejecuta AL MENOS UNA VEZ y luego revisa.

7. **¿Para qué utilizamos `for` en nuestro programa?**
   → Para dibujar la barra de progreso repitiendo un bloque de código de 10 en 10 hasta 100.

8. **¿Qué sucede si eliminamos una de las reglas del modelo?**
   → El puntaje de riesgo cambia y la predicción puede ser incorrecta porque falta información.

9. **¿Por qué nuestra Mini-IA no es realmente un modelo de Machine Learning?**
   → Porque las reglas las escribimos nosotros a mano; en ML el sistema aprende las reglas solo de los datos.

10. **¿Qué necesitaríamos para que el sistema aprendiera automáticamente las reglas a partir de datos?**
    → Una gran cantidad de datos conocidos + un algoritmo que encuentre patrones y calcule sus propias reglas.
